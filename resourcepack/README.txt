CelestHub Resource Pack (Jukebox)

1) Put your OGG files here:
   assets/celest/sounds/music/lobby_theme1.ogg
   assets/celest/sounds/music/lobby_theme2.ogg

2) Zip the CONTENTS of this folder (not the folder itself):
   pack.mcmeta
   assets/

3) Upload the zip and set it as server resource pack.

4) Keep feature keys in plugin config as:
   celest:lobby.theme1
   celest:lobby.theme2

5) Adjust duration in:
   src/main/resources/features/jukebox.yml
   JUKEBOX.TRACKS.*.DURATION_SECONDS
